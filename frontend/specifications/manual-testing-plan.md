## Передумови

### Підготовка середовища

1. **Backend запущений** на `http://localhost:8000`
2. **Frontend запущений** на `http://localhost:4200`
3. **Чиста база даних** (або тестовий користувач)
4. **Різні браузери**: Chrome, Firefox, Safari
5. **Різні пристрої**: Desktop, Tablet, Mobile

### Тестові дані

```
Email: test@example.com
Password: Test1234!
Name: Test User
```
